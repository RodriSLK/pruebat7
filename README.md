# 📝 Lista de Tareas - React

## 📌 Descripción del proyecto

Este repositorio contiene el desarrollo de una aplicación web de gestión de tareas (To-Do List) realizada como trabajo práctico académico.

La finalidad principal del proyecto fue aplicar conceptos fundamentales de desarrollo frontend utilizando React, construyendo una interfaz interactiva que permita administrar tareas de manera simple y dinámica.

A través de este proyecto se trabajó sobre la creación de componentes reutilizables, manejo de estado, renderizado dinámico de información y buenas prácticas de desarrollo.

---

## 🎯 Objetivos

* Desarrollar una aplicación funcional para la administración de tareas.
* Aplicar conceptos fundamentales de React.
* Implementar pruebas automatizadas para validar el funcionamiento.
* Utilizar herramientas modernas de desarrollo frontend.
* Mantener buenas prácticas de organización y calidad de código.

---

## ✨ Funcionalidades implementadas

* ➕ Agregar nuevas tareas.
* 📋 Visualizar listado de tareas.
* ✅ Marcar tareas como completadas.
* ❌ Eliminar tareas.
* 🔄 Actualización dinámica de la interfaz.

## ⚙️ Instalación y ejecución

### Clonar repositorio

```bash

```

### Instalar dependencias

```bash
npm install
```

### Ejecutar proyecto

```bash

```
